# Manager ServSafe Study Guide Web App

Simple static web app for people studying food manager / ServSafe-style food safety topics.

## Run locally

```bash
cd /home/chris/projects/servsafe-manager-study
python3 -m http.server 8585 --bind 0.0.0.0
```

Then open:

- Local: http://127.0.0.1:8585

## Features

- Flashcards by category
- Tap-to-flip cards
- Mark known progress saved in the browser
- 10-question randomized practice quiz
- Quick temperature cheat sheet
- Simple mobile-friendly layout

This is a study aid, not an official ServSafe exam or answer key.
