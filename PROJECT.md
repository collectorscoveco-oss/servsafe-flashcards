# P012 — ServSafe Florida Flashcards

Status: Prototype v0.2.0 debug APK built for sideload testing.

Goal: Android multiple-choice study guide for Florida manager ServSafe / Certified Food Protection Manager exam prep with Florida-specific certification reminders.

Current features:
- 202 original multiple-choice study questions across categories.
- Four answer choices per question with immediate correct/review feedback.
- Category filter, text search, shuffle, next/previous.
- Correct answers auto-mark as known; missed answers auto-mark for review; manual Mark known/Mark again buttons remain.
- Florida manager certification notes and study-aid disclaimer.

Tech stack: Native Android Java, Gradle Android Plugin 8.7.3, minSdk 23, targetSdk 35.

Next steps:

- Add missed-card-only deck, timed exam mode, and scoring summary if desired.
- Add custom icon polish/screenshots before any Play Store path.
