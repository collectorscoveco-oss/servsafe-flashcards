# P012 — ServSafe Florida Flashcards

Status: Prototype v0.1.0 debug APK built for sideload testing.

Goal: Android flashcard study guide for ServSafe Manager certification with Florida-specific certification reminders.

Current features:
- 202 original flashcards across categories.
- Category filter, text search, shuffle, next/previous, tap-to-flip.
- Mark cards as known or again; progress stored locally with SharedPreferences.
- Florida certification notes and exam disclaimer.

Tech stack: Native Android Java, Gradle Android Plugin 8.7.3, minSdk 23, targetSdk 35.

Next steps:
- Test on Android phone.
- Add practice quiz mode and missed-card-only deck if desired.
- Add custom icon polish/screenshots before any Play Store path.
